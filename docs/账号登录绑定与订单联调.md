# 账号登录、绑定与订单联调

## 身份规则

- Web 支持邮箱验证码、微信扫码和兼容账号密码登录；小程序使用 `wx.login` 登录。
- 邮箱验证码 10 分钟有效、最多尝试 5 次，同一邮箱 60 秒内不能重复发送。验证码邮件主题不会触发微信快捷指令。
- Web 在个人中心可绑定微信，小程序在个人中心可绑定邮箱。绑定已有账号会合并好友、任务、模板、订单和会员权益；存在重复接收邮箱、重复变量名或两边已绑定不同身份时拒绝合并，不覆盖数据。
- 扫码 ticket 为 26 个字符，5 分钟有效。浏览器另持有独立 `pollSecret`，仅知道 ticket 不能取得登录令牌；小程序必须展示确认页面并由用户主动确认。

## 开发 ticket

体验版联调：

```dotenv
WECHAT_MINI_ENV_VERSION=trial
AUTH_SHOW_DEV_TICKET=true
```

在微信开发者工具中打开 `pages/scan/index`，启动参数填 `scene=网页显示的ticket`。正式版：

```dotenv
WECHAT_MINI_ENV_VERSION=release
AUTH_SHOW_DEV_TICKET=false
```

小程序码固定进入 `pages/scan/index`。必须先发布对应页面；开发版生成失败时可使用 ticket 联调。

## 订单闭环验收

1. 管理员创建套餐并配置支付渠道。支付宝私钥和微信 AppKey 只提交给服务端，页面只返回“是否已配置”。
2. 用户创建订单，同用户同套餐的短时重复点击会复用有效待支付订单。
3. 支付后以平台验签通知或服务端主动查单为准，客户端 `success` 不发放权益。
4. 在 Web 订单中心或小程序“我的 → 订单记录”确认创建、支付、通知/发货、最近查单时间。
5. 开启“发送任务需要有效会员权益”，创建多好友任务后确认额度按收件人数增长；取消未发送任务后对应额度退回。
6. 在沙箱/测试环境验证正常支付、用户取消、断网、重复/延迟回调、超时和退款。退款查单后会员权益应失效。

线上升级前备份 PostgreSQL，再运行迁移。不要在自动化测试中使用真实支付凭据或触发真实收款。
