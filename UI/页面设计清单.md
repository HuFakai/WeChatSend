# 页面设计清单与双端功能对齐

状态：用户已选 A 黑白极简。以下为完整产品页面地图，不代表都已出图。先完成 MVP 双端页面确认，其他模块随阶段设计，范围以 [分阶段开发计划](../docs/分阶段开发计划.md) 为准。

MVP 只设计：账号密码登录、简要工作台、发送账号与邮箱验证/测试、好友手工/粘贴导入与多选、手工文案新建任务（立即/单次定时及间隔）、任务列表/详情/取消。分组标签、草稿、模板、变量、AI、扫码及管理员内容页面分别在后续阶段交付。

| 页面组 | Web 页面/状态 | 小程序功能对应 |
| --- | --- | --- |
| 登录 | 账号密码、注册、扫码待确认/失效 | 账号密码/微信登录、绑定、网页登录确认 |
| 工作台 | 任务摘要、快捷入口、配置指引 | 相同摘要和全部工具入口 |
| 发送账号 | 列表、新增编辑、邮箱验证、测试、停用 | 同等能力，表单分步 |
| 好友 | 筛选、批量选择、编辑、停用、分组标签 | 同等能力，列表卡片及批量操作栏 |
| 好友导入 | 手工、分隔符粘贴、截图 AI、候选确认与冲突 | 同等导入方式与确认能力 |
| 模板中心 | 平台/我的/收藏、行业场景筛选、模板详情 | 同等浏览、收藏、复制及管理 |
| 模板编辑 | 文本、变量插入、预览、AI 改写、保存 | 同等编辑器，底部抽屉插入变量 |
| 变量库 | 内置/自定义、固定/随机/顺序、候选值、Excel/CSV | 同等模式、文件导入、错误预览与确认 |
| 任务中心 | 状态筛选、搜索、列表、草稿和定时 | 同等查询和管理，本轮出图页 |
| 新建任务 | 文案 → 账号/好友 → 变量和时间/间隔 → 预览提交 | 完整步骤，移动端逐屏推进 |
| 任务详情 | 汇总、逐好友邮件明细、尝试记录、取消未发项 | 同等细节、筛选、取消及人工重发入口 |
| AI 助手 | 文案/模板生成、任务草稿、缺失信息、确认 | 同等能力；没有确认不发送 |
| 设置 | 时区、地区、身份绑定、账号安全、通知 | 同等设置，额外承接扫码确认入口 |
| 管理员内容 | 审核、发布、停用、行业标签、平台变量 | 同一管理员角色可完成同样操作 |

完整产品移动端底部入口初稿：工作台、任务、内容、我的。MVP 只显示工作台、任务、我的；我的提供发送账号、好友及退出入口，内容在 P2 加入，AI 等入口随阶段开放。当前 A 风格图中的完整导航不是 MVP 功能范围。

每组补充空状态、加载、无权限、错误、成功反馈；重点补充截图低确定性/重复备注、变量缺失、邮件结果未知、取消部分完成、扫码过期。信息完整性优先于让移动端与桌面长得完全一样。

设计约束：不得显示未经证实的微信送达、设备在线、转化率；邮件状态文案准确；“定时”说明为开始排队时间。正式图的按钮、状态、数据与字段在定稿时逐项校对。

流程：A 风格已选 → MVP 双端页面及状态图 → 用户确认 → MVP 开发验收 → 后续阶段逐项设计及实现。不得因风格已选而默认完整页面也已确认。
